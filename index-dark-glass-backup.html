Prompt Library

Structure before you build.

How to structure a Shopify build so AI doesn't break it midway. AI builds each screen beautifully — in isolation. By screen 8, nothing lines up. The fix isn't a better prompt; it's structure set before the first screen.

Why AI breaks midway

AI optimises each screen on its own. Without a structure holding the pieces together, the navigation stops matching, data shapes clash, and components get duplicated — and it all wobbles at once.

1

Map the whole thing first

Why — AI without the full map optimises each screen locally and breaks the big picture.
How — List every page and section up front, so the AI always knows where the current screen fits in the whole store.
2

Lock the design system early

Why — Define it after the fact and every screen drifts — different spacing, colours, components.
How — Set colours, type, spacing, and components once, up front. Every screen inherits them — which also keeps the UI from looking AI-generated.
3

Build section by section

Why — "Build the whole app" makes the AI juggle everything at once — that's where it collapses.
How — One screen at a time. Build it, review it, then the next — each referencing the shared map and system.
4

Decide the data shape up front

Why — If screens invent their own versions of a product or order, the data clashes when you connect them.
How — Define what a product, collection, and order look like early, so every screen speaks the same data language.
The Structure Prompt · Build inside a structure
Before we build any screen, we're setting the structure for the whole store. 1. First, map it: list every page and section, in order, and how they connect. Confirm this map before building anything. 2. Lock a design system now — colours, type, spacing, and shared components. Every screen must inherit it exactly; never redefine styles per screen. 3. Define the core data shapes up front — what a product, collection, and order look like — so every screen uses the same structure. 4. Then build one screen at a time. After each screen, stop so I can review before the next. Every screen must reference the map, the design system, and the data shapes above — never build in isolation. Start with the map. Do not generate any screen until I confirm it.

The rule of thumb — if the AI is building a screen without referencing the map, the system, and the data shapes, stop. That's the moment it starts drifting toward the screen-8 collapse.
